### What I've Been Working On

- **🏗️Building Models from Scratch:**
  I'm focused on building custom models and architectures and kernel optimisation. My work includes:
  - **LSTM Models:** Developed Long Short-Term Memory networks for time-series forecasting in air quality monitoring and electrical transformer maintenance.
  - **Anomaly Detection:** Built ML models to analyze flight patterns and detect spoofing attempts in UAV fleets.
  - **Custom Embeddings:** Designed specialized embedding models and retrieval pipelines for domain-specific query understanding.

- **🤖 GraphRAG & Fine-Tuning:**
  I recently built a **GraphRAG Fine-tune Pipeline**, a comprehensive system integrating Neo4j knowledge graphs with LangChain agents. It features:
  - A **Document Ingestion Pipeline** for extracting entities/relationships.
  - A **RAG Query Agent** utilizing hybrid retrieval (Vector + Cypher).
  - A **Training Pipeline** that generates synthetic data to fine-tune LLMs for better Cypher query generation.

### System Architecture & Engineering Principles

* **Software Design & Scalability:** Architecting modular backends using **SOLID principles** and **Design Patterns**. Leveraging **Pydantic** for type-safe data validation and building reusable components in complex AI workflows.
* **Durable Orchestration:** Implementing fault-tolerant, long-running processes using **Temporal** for durable execution. Managing agentic state and complex logic transitions through **LangGraph** and **Semantic Kernel**.
* **Data Integrity & Evolution:** Managing production-grade relational data with **MySQL**, ensuring safe schema migrations via **Alembic**, and architecting high-performance memory layers using **Redis** and **Mem0**.
* **Performance & GPU Optimization:** Addressing latency bottlenecks by writing custom **Triton/CUDA** kernels for specialized neural architectures (LSTMs, Transformers) and optimizing inference at the metal level.
* **Infrastructure & Reliability:** Provisioning reproducible environments with **Terraform** and **Kubernetes**. Ensuring system reliability through **Azure DevOps** CI/CD and implementing rate-limiting and circuit breakers to handle high-concurrency workloads.
* **Observability:** Integrating **OpenTelemetry** and the **LGTM stack** (Loki, Grafana, Tempo, Mimir) for full-stack tracing, allowing for granular monitoring of agentic reasoning and system performance.
